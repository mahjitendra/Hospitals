# Hospital ERP

A comprehensive Hospital ERP system built with PHP following the MVC pattern.

This project is currently under development.

## Project Overview

This ERP system aims to cover all aspects of hospital management, including:
- Patient Management
- Clinical Workflow
- Appointments and Scheduling
- Pharmacy and Inventory
- Laboratory and Radiology
- Billing and Financials
- Human Resources
- Reporting and Analytics
- And more...

## Installation

Detailed installation instructions will be provided in the `docs` directory.

```bash
# Clone the repository
git clone https://github.com/your-repo/hospital-erp.git

# Navigate to the project directory
cd hospital-erp

# Install Composer dependencies
composer install

# Create your environment file
cp .env.example .env

# Configure your .env file with database and other settings
# ...
```
